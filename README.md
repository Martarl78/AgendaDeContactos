# # 📒 Agenda de Contactos en Kotlin

---

## ✨ Funcionalidades

| Opción | Descripción |
|:------:|-------------|
| **1** | **Añadir contacto**: solicita nombre, teléfono y correo electrónico. |
| **2** | **Listar contactos**: muestra todos los contactos numerados y ordenados por nombre. |
| **3** | **Buscar contacto**: búsqueda por nombre con coincidencia total o parcial (sin distinguir mayúsculas). |
| **4** | **Eliminar contacto**: por número de posición o por nombre, mostrando antes la lista. |
| **5** | **Salir** del programa. |
